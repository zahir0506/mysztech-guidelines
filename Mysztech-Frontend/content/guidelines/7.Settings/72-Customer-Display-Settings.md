You can set up the customer display from both **Management Hub** and the **POS System**. Management Hub provides more options for creating and managing slideshows, while the POS System provides the basic customer display settings.

1\.	Go to **Management Hub**.

![](</admin/7. Settings/Screenshot-2026-09-22-124455.png>)

2\.	Go to **Settings > Slideshows**. You will see a list of all slideshows that have been created.

![](</admin/7. Settings/Screenshot-2026-09-22-124547.png>)

3\.	Click **New Slideshow** to create a new slideshow.

![](</admin/7. Settings/Screenshot-2026-09-22-124638.png>)

4\.	Select the **Outlet** where you want to use the slideshow.

![](</admin/7. Settings/Screenshot-2026-09-22-125301.png>)

5\.	Enter the **Title** for the slideshow.

![](</admin/7. Settings/Screenshot-2026-09-22-125429.png>)

6\.	Enter a **Description.** This is optional.

![](</admin/7. Settings/Screenshot-2026-09-22-125519.png>)

7\.	Enter a **Greetings** message for customers.

![](</admin/7. Settings/Screenshot-2026-09-22-125619.png>)

8\.	Enter a **Feedback Description**. This is optional.

![](</admin/7. Settings/Screenshot-2026-09-22-125714.png>)

9\.	Add a **Promotional Link** if you want to show a promotion.

![](</admin/7. Settings/Screenshot-2026-09-22-125758.png>)

10\.	Add an **Image** if you want to show an image on the customer display.

![](</admin/7. Settings/Screenshot-2026-09-22-125842.png>)

11\.	Add a **Payment Page Image** if you want to show an image on the payment page.

![](</admin/7. Settings/Screenshot-2026-09-22-125931.png>)

12\.	Check the information and save the slideshow.

![](</admin/7. Settings/Screenshot-2026-09-22-130002.png>)

13\.	Go to the **POS System**. 

![](</admin/7. Settings/Screenshot-2026-09-22-143011.png>)

14\.	Go to **Settings > Customer Display.**

![](</admin/7. Settings/Screenshot-2026-09-22-143124.png>)

15\.	The POS System also allows you to set the **Title, Description, Greeting, Feedback Description, and Promotion Link.**

**Note:** The POS System has fewer settings than Management Hub. 

![](</admin/7. Settings/Screenshot-2026-09-22-143219.png>)

16\.	Click **Save & Show Secondary Display** to save the settings and show the customer display. 

![](</admin/7. Settings/Screenshot-2026-09-22-143314.png>)

17\.	Click **Stop Display** if you want to stop showing the customer display. 

![](</admin/7. Settings/Screenshot-2026-09-22-143415.png>)
