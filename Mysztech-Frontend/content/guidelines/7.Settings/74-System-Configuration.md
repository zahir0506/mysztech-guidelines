1\.	Go to **Settings > System Config.** 

![](</admin/7. Settings/Screenshot-2026-09-22-143757.png>)

2\.	You can view the system configuration and the **App Version** to check which version the POS System is using. 

![](</admin/7. Settings/Screenshot-2026-09-22-143841.png>)

3\.	**Main Device** – Enable or disable this option to set the device as the main POS device for the outlet. 

![](</admin/7. Settings/Screenshot-2026-09-22-143926.png>)

4\.	**Force Sync** – Click **Force Sync** to sync all data with the server. This will download all data, including images. 

![](</admin/7. Settings/Screenshot-2026-09-22-144017.png>)

5\.	**Realtime Status** – Check whether the POS System is connected or not. 

![](</admin/7. Settings/Screenshot-2026-09-22-144055.png>)

6\.	**Pending Changes to Cloud –** Check the last sync time and whether all data has been synced. You can also click **Start** or **Stop** to control the sync. 

![](</admin/7. Settings/Screenshot-2026-09-22-144148.png>)

7\.	**Print Queue Monitoring** – Check if there are any pending print jobs. You can also **Start** or **Stop** print queue monitoring. 

![](</admin/7. Settings/Screenshot-2026-09-22-144247.png>)

8\.	**Debug Mode** – Use this to record app logs to help find and diagnose issues. Click **Start Recording** to start recording. 

![](</admin/7. Settings/Screenshot-2026-09-22-144343.png>)

9\.	After recording, click **Stop & Report** to report a bug. Describe the issue in the provided box and click **Submit Report** to send the report. 

![](</admin/7. Settings/Screenshot-2026-09-22-144429.png>)

10\.	**Internet Speed** – Click **Test Speed** to check the internet speed. 

![](</admin/7. Settings/Screenshot-2026-09-22-144511.png>)

11\.	**Cleanup Data** – Click **Cleanup Data** to remove corrupted or leftover data. Your **orders, receipts, and settings will not be affected.** 

![](</admin/7. Settings/Screenshot-2026-09-22-144614.png>)
