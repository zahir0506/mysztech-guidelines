1\.	Select the section you want to update, then press the Edit button at the top right .

(e.g. Section 5).

&#x20;![](</admin/3. Restaurant Table Layout/Picture3-11.jpg>)

2\.	Select the Edit button (pencil icon) to make changes to the selected section.

&#x20;![](</admin/3. Restaurant Table Layout/Picture3-12.jpg>)

3\.	Tap Name Field (Section 5), delete it, and type your new name.

![](</admin/3. Restaurant Table Layout/Picture3-13.jpg>)

4\.	After typing your new name (e.g. OUTDOOR), select the Save button to see the changes.

![](</admin/3. Restaurant Table Layout/Picture3-14.jpg>)

![](</admin/3. Restaurant Table Layout/Picture3-15.jpg>)

5\.	Select Background Texture, then choose Mosaic. The background will show a mosaic effect.

![](</admin/3. Restaurant Table Layout/Picture3-16.jpg>)![](</admin/3. Restaurant Table Layout/Picture3-17.jpg>)

6\.	Select Background Texture, then choose Wood. The background will show a wood effect.

![](</admin/3. Restaurant Table Layout/Picture3-18.jpg>)![](</admin/3. Restaurant Table Layout/Picture3-19.jpg>)

7\.	Press Choose Color to change the background color.

&#x20;![](</admin/3. Restaurant Table Layout/Picture3-20.jpg>)

8\.	Adjust sliders (Hue, Saturation, and Brightness), then press Select to apply the color.

![](</admin/3. Restaurant Table Layout/Picture3-21.jpg>)

9\.	Select Save button to apply the background color.

&#x20;![](</admin/3. Restaurant Table Layout/Picture3-22.jpg>)

10\.	Select the Save button to apply the changes. You have successfully changed your background colour.

![](</admin/3. Restaurant Table Layout/Picture3-23.jpg>)
