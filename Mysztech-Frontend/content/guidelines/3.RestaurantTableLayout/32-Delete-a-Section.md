1\.	Select Edit button at top right.

&#x20;![](</admin/3. Restaurant Table Layout/Picture3-6.jpg>)

2\.	Select the Edit button for the section you want to delete ( e.g. Section 5).

![](</admin/3. Restaurant Table Layout/Picture3-7.jpg>)

3\.	Select the delete button to delete the section you want to delete.

&#x20;![](</admin/3. Restaurant Table Layout/Picture3-8.jpg>)

4\.	Select the save button at the top right to save changes you made.

&#x20;![](</admin/3. Restaurant Table Layout/Picture3-9.jpg>)

5\.	You have successfully deleted the section (e.g. Section 5  no longer exist).

![](</admin/3. Restaurant Table Layout/Picture3-10.jpg>)
