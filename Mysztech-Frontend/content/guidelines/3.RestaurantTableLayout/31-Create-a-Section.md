1\.	Select the Layout icon at the bottom of the page.

![](</admin/3. Restaurant Table Layout/Picture3-1.jpg>)

2\.	Select Edit button at the top right to create a section.

![](</admin/3. Restaurant Table Layout/Picture3-2.jpg>)

3\.	Select + Add Section button.

![](</admin/3. Restaurant Table Layout/Picture3-3.jpg>)

4\.	Select the Save button at the top right to save changes.

![](</admin/3. Restaurant Table Layout/Picture3-4.jpg>)

5\.	 You have successfully created a section.

![](</admin/3. Restaurant Table Layout/Picture3-5.jpg>)
