There are several ways to remove or close an order depending on what you want to do.

**A. Delete an Order**

Use this when you want to completely delete an order that has already been taken.

1\.	Go to **Open Order.**

![](</admin/5. Manage Order /Screenshot-2026-09-21-092902.png>)

2\.	Select the **square box** next to the order you want to delete.

![](</admin/5. Manage Order /Screenshot-2026-09-21-093013.png>)

3\.	Tap the **Delete** icon at the top.

![](</admin/5. Manage Order /Screenshot-2026-09-21-093425.png>)

4\.	After that, tap **Confirm** to remove the order from the active order list. 

Note : When deleting an order, tick **Print Void Receipt** if you want the kitchen printer to print a cancellation notice. This lets the kitchen staff know that the order has been cancelled and should not be prepared.

![](</admin/5. Manage Order /Screenshot-2026-09-21-093544.png>)

5\.	The order has been removed from the **Active Order List**. Notice that **Order No. 101** is no longer displayed.

![](</admin/5. Manage Order /Screenshot-2026-09-21-093642.png>)

**Another way to delete an order:**

1\.	Go to **Open Order** and select the order you want to delete (e.g. Order No.101).

![](</admin/5. Manage Order /Screenshot-2026-09-21-093749.png>)

2\.	Tap the **3-dot menu** at the top.

![](</admin/5. Manage Order /Screenshot-2026-09-21-094623.png>)

3\.	Select **Void Order**.

![](</admin/5. Manage Order /Screenshot-2026-09-21-094712.png>)

4\.	Tap **Void** to confirm.

![](</admin/5. Manage Order /Screenshot-2026-09-21-094805.png>)

**B. Remove an Item from an Order**

Use this when you only want to remove one item from an order.

**Steps:**

1\.	Swipe the item to the **right**.

![](</admin/5. Manage Order /Screenshot-2026-09-21-094912.png>)

2\.	The item will be removed from the order.

![](</admin/5. Manage Order /Screenshot-2026-09-21-095031.png>)

3\.	Tap **Save** to save the changes.

![](</admin/5. Manage Order /Screenshot-2026-09-21-095242.png>)

**C. Close an Order Without Making Changes**

Use this when you accidentally open an order from **Open Order** and do not make any changes.

**Note: Close Order** does not delete the order. It only closes the order and removes it from the current order display.

**Steps:**

1\.	Tap the **3-dot menu** at the top.

![](</admin/5. Manage Order /Screenshot-2026-09-21-100346.png>)

2\.	Tap **Close Order.**

![](</admin/5. Manage Order /Screenshot-2026-09-21-100444.png>)

3\.	Tap **Close** to close the order.

![](</admin/5. Manage Order /Screenshot-2026-09-21-100610.png>)

4\.	You have successfully closed the order. You can verify that the order is still available in the **Open Order List.**

![](</admin/5. Manage Order /Screenshot-2026-09-21-100747.png>)

**D. Remove an Order from a Table**

Use this when an order was assigned to the **wrong table.**

Note: Removing an order from a table does **not** delete the order. It only removes the table assignment. The order can still be found in **Open Order.**

**Steps:**

1\.	Go to **Table Layout.**

![](</admin/5. Manage Order /Screenshot-2026-09-21-101205.png>)

2\.	Select the table with the order (e.g. T3).

![](</admin/5. Manage Order /Screenshot-2026-09-21-103509.png>)

3\.	Tap **Unlink button** at the top, beside **Close button.**

![](</admin/5. Manage Order /Screenshot-2026-09-21-103556.png>)

4\.	The order has been removed from the table (e.g., T3).

![](</admin/5. Manage Order /Screenshot-2026-09-21-103645.png>)

You can verify the order by going to **Open Order.**
