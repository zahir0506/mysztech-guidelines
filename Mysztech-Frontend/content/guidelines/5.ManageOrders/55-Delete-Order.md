An order is submitted when you tap Save after taking or editing an order.

When the order is saved, the system will send each item to the printer assigned to its department.

**Order Printing Flow**

The system checks the items in the order and sends them to the correct department printer.

For example:

**Order:**

•	Nasi Goreng

•	Teh Cold

**Printing:**

•	Nasi Goreng → **Kitchen Printer**

•	Teh Cold → **Beverages Printer**

This allows each department to receive only the items they need to prepare.

**Example of the Order Flow**

1\.	Take the customer's order.

![](</admin/5. Manage Order /Pic33.png>)

2\.	Tap **Save** button.

![](</admin/5. Manage Order /Screenshot-2026-09-17-171342.png>)

3\.	You can choose to create an order using an **Order Number** or a **Custom Order**.

**Order Number:** Tap any available order number to save the order under that order number (e.g. Order Number 101).

![](</admin/5. Manage Order /Pic34.png>)

**Custom Order:** Press the **Edit** button (pencil icon) to create a custom order and press Save.

![](</admin/5. Manage Order /Screenshot-2026-09-17-171536.png>)

**Note:** Each item is sent to its assigned department printer. The **Kitchen** receives the food items.The **Beverages** department receives the drink items. The order will only be printed to a department if the item has been assigned to a printer for that department.
