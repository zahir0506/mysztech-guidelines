1\.	Press the New Category button to create a category.

![](</admin/4. Sales Screen and Items/4.2/Picture1-4.2.png>)

2\.	Type the name of your category in the box, then choose the color you prefer.

![](</admin/4. Sales Screen and Items/4.2/Picture2-4.2.png>)

3\.	After checking what you entered, press the Create button to finish making the category.

![](</admin/4. Sales Screen and Items/4.2/Picture3-4.2.png>)

4\.	You have successfully created a category. Check the category list to verify that the new category has been created.

![](</admin/4. Sales Screen and Items/4.2/Picture4-4.2.jpg>)

**Two Ways to Add Variants (on Item Creation Page)**

•	Option A – Use Predefined Variants

👉 Select from the list of variants that were already created earlier (e.g., Size = Small, Medium, Large). Best when you want consistency across many items.

**Click Here to Create Predefined Variants**

* Option B – Create New Variants for This Item

👉 Add variant options directly in the Variants section below (e.g., TEH O = Hot, Cold). Best when the variant is unique to this item.

**Continue on this page and add variant options directly under the Variants section**

5\. Select the predefined variant if you already created it, or start adding the variant’s attributes. The required field is Name, while Price, Cost, SKU, and Barcode are optional.

6\.	Click the “Add variant option” button to add more variants (for example, Hot, Cold) and make sure to enter a price for each variant.

7\. Scroll down to the Outlets section and select the outlet where you want this item to be

displayed.
