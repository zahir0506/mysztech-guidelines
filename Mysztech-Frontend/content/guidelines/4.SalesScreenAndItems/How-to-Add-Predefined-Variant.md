Predefined variants are options (like Size = Small, Medium, Large) that were created earlier in the Backoffice (Management Hub), and on the Item Creation Page you can select them directly instead of making new ones.

*[Click Here to know how to access Management Hub](http://localhost:5173/docs?id=How-to-access-Management-Hub)*

1\.	Scroll down in the sidebar, find Variants under the Item section, click it, and go into the Variants page.

![](</admin/4. Sales Screen and Items/How to add predefined Variant/Picture1-variant.png>)

2\.	Click the "+ New Variant" blue button to start creating a new variant.

&#x20;![](</admin/4. Sales Screen and Items/How to add predefined Variant/Picture10-variant.png>)

3\.	Start by creating a general name for the variant you are setting up; this name is only for you to recognize and manage it, and it will not appear in the POS system.

**Options and Variant Options**

* **Options**
  * Each option has two parts:
    * **Option Name** → The label (e.g., Size, Cup Material).
    * **Option Values** → The choices under that label (e.g., Small, Large, Plastic, Glass).


  * The values you type here will automatically be assigned to the Variant Option’s Name, and the system will generate all possible combinations.
  * Example: Size (Small, Large) + Cup Material (Plastic, Glass) = 4 Variant Options (Small/Plastic, Small/Glass, Large/Plastic, Large/Glass).
* **Variant Options**
  * This section shows the combinations created from your Option Values.
  * Each combination can have its own price, cost, SKU, and barcode.


**Reminder for Users**

If this feels too technical or confusing, you can **skip filling in Option Values** and instead **add Variant Options manually** in the Variant Options section. This way, you only create the exact variants you need without worrying about automatic combinations.

Reminder: This method is useful if you **find the automatic combinations confusing** or if you only need a few specific variants. It gives **you direct control to create exactly the variants you want** without relying on the Options setup.

4\. Start by adding an Option Name (for example, Size) and then type the Option Value (for example, Small). Click the "Add to option Values" button if you want to add more values such as Medium or Large add the values.

Note: Each value you add here will automatically appear in the Variant Options section, where you can set price, cost, SKU, and barcode for each combination.![](</admin/4. Sales Screen and Items/How to add predefined Variant/Picture4-variant.png>)

5\. For example, if you add values “Medium, Large” as Option Values, you will see 3 rows appear in the Variant Options section because you entered 3 option values (Small, Medium, Large).

![](</admin/4. Sales Screen and Items/How to add predefined Variant/Picture5-variant.png>)

6\.  If you want to add more options, click the “Add to options” button and repeat the same step. If you don’t need more options, go to the Variant Options section and add a price for every variant listed.

Note: The price field is required, so don’t leave it empty. If the price is zero, type RM0 to avoid errors.

![](</admin/4. Sales Screen and Items/How to add predefined Variant/Picture6-variant.png>)

7\. Scroll down and you will find the Outlet section. Select the outlet where you want this variant to be available, then click the Create button at the top right.

Note: Make sure you choose the correct outlet before creating, because the variant will only be active in the outlet you select.

![](</admin/4. Sales Screen and Items/How to add predefined Variant/Picture7-variant.png>)

8\. You successfully created a variant. You can verify it by searching for the variant name in the system.

Note: Always double-check the name you entered to confirm the variant is saved correctly and linked to the right outlet.

![](</admin/4. Sales Screen and Items/How to add predefined Variant/Picture8-variant.png>)
