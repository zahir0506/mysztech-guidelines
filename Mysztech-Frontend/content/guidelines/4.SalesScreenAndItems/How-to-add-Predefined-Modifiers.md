A **Predefined Modifier** is a ready made customization option (like “Low Sugar,” “More Ice,” “Less Ice”) that was created earlier in the Backoffice. Its purpose in the POS system is to save time and ensure consistency, because staff can quickly reuse the same modifier across multiple items.

*[Click Here to know how to access Management Hub](http://localhost:5173/docs?id=How-to-access-Management-Hub)*

1\.	Scroll down in the sidebar, find Modifiers under the Item section, click it, and go into the Modifiers page.

![](</admin/4. Sales Screen and Items/How to add Predefined Modifiers/Picture1-Modifiers.png>)

2\.	Click the "+ New Modifier" blue button to start creating a new modifier.

![](</admin/4. Sales Screen and Items/How to add Predefined Modifiers/Picture2-Modifiers.png>)

3\.	Start by creating a general name for the modifier you are setting up; this name is only for you to recognize and manage it, and it will not appear in the POS system.

![](</admin/4. Sales Screen and Items/How to add Predefined Modifiers/Picture3-Modifiers.png>)

4\.	Then, select as many categories as you want (you can choose more than one) where you want this modifier to appear.

Turn on the “Apply to all items under the selected categories” button so the modifier will automatically display for every item inside those categories.

**Note: This ensures consistency and saves time, since you don’t need to manually attach the modifier to each item one by one.**

![](</admin/4. Sales Screen and Items/How to add Predefined Modifiers/Picture4-Modifiers.png>)

5\.	Type in the modifier’s Name, Price (required), and Cost (optional).

If you have more than one modifier, click the “Add modifier option” button below — this will insert an empty row for you to add additional modifiers.

**Note: Always enter a value in the Price field (even RM0 if free) to prevent system errors.**

![](</admin/4. Sales Screen and Items/How to add Predefined Modifiers/Picture5-Modifiers.png>)

6\.	Scroll down to the Outlets section and select the outlets where you want this modifier to appear.

Click the “Select all outlets” button to automatically select every outlet at once, making the process faster and effortless.

![](</admin/4. Sales Screen and Items/How to add Predefined Modifiers/Picture6-Modifiers.png>)

7\.	Reconfirm everything you entered — the modifier name, price, cost, and selected outlets.

Once all details are correct, press the Create button to save the modifier.

![](</admin/4. Sales Screen and Items/How to add Predefined Modifiers/Picture7-Modifiers.png>)

8\.	You have successfully created a modifier. You can verify it by searching for the modifier’s name in the **Modifiers** section.

![](</admin/4. Sales Screen and Items/How to add Predefined Modifiers/Picture8-Modifiers.png>)

9\.	After you have created the modifier, go to the Modifiers section, select Add Modifier, then search for the modifier you just created (e.g. Beverages Add Ons) and choose it to attach it to the item.

![](</admin/4. Sales Screen and Items/How to add Predefined Modifiers/Picture9-Modifiers.png>)

10\. In the Required Option section, you can set how many modifiers must be selected for the item. This step is optional, so you can leave it blank if not needed. If you don’t set anything, just double check the modifier name you entered, then scroll down to the Representation on POS section to continue.

![](</admin/4. Sales Screen and Items/How to add Predefined Modifiers/Picture10-Modifiers.png>)

11\. You can set an image or choose a shape and color that you prefer in the Representation on POS section. This is the visual appearance that will show up in the POS system for the item, so pick the style that best represents it.

![](</admin/4. Sales Screen and Items/How to add Predefined Modifiers/Picture11-Modifiers.png>)

12\. To set an image for the item, enable the Use Image button in the Representation on POS section, then either select an image from your files or drag and drop it into the field. Remember, the supported file formats are PNG, JPEG, and JPG. This image will be the visual shown in the POS system for the item.

**Skip this step if you don’t want to use images and prefer shapes instead.**

![](</admin/4. Sales Screen and Items/How to add Predefined Modifiers/Picture12-Modifiers.png>)

13\. To set shapes and color, select a shape such as Square, Circle, or Triangle, then choose the color you prefer. After confirming your choice, click the Create button at the top to finalize and create the item.

![](</admin/4. Sales Screen and Items/How to add Predefined Modifiers/Picture13-Modifiers.png>)

14\. You have successfully created an item.

![](</admin/4. Sales Screen and Items/How to add Predefined Modifiers/Picture14-Modifiers.png>)
